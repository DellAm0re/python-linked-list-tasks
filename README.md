# Практична робота — Пов’язаний список (Linked List)

**Мова:** Python 3. **Тема:** однозв’язні списки та операції з вузлами.

## Завдання

| Файл | Опис |
|---|---|
| `task01.py` | Злиття двох відсортованих списків |
| `task02.py` | Видалення дублікатів із відсортованого списку |
| `task03.py` | Виявлення циклу (алгоритм Флойда) |
| `task04.py` | Перевпорядкування L0 → Ln → L1 → Ln−1 |
| `task05.py` | Видалення вузла без доступу до `head` |
| `task06.py` | Подвоєння числа, записаного у вузлах |
| `task07.py` | Злиття k відсортованих списків (мін-купа) |
| `task08.py` | Розворот вузлів групами по k |
| `task09.py` | Стабільний поділ списку за значенням x |

`linked_list.py` містить клас `ListNode` і допоміжні функції для створення та виведення списків. Основні функції працюють із вузлами, а не з масивами Python. У задачах 1, 4, 8 і 9 змінюються посилання між наявними вузлами.

## Запуск

Відкрийте термінал у папці проєкту та виконайте:

```bash
python task01.py
```

Аналогічно запускаються `task02.py` — `task09.py`. Сторонніх бібліотек не потрібно.
